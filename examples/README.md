# Examples

Small, standalone pieces you can lift into your own work. Every figure comes from the SpaceParts data and is checked against `labs/01-data-agent/verify_answers.sql`.

| Folder | What's in it |
| --- | --- |
| [`charts/`](charts/README.md) | A gallery of five chart forms for agent answers (budget markers, diverging gaps, ranked bars, small multiples, dot plots), plain SVG, opens offline |
| [`embedding/`](embedding/README.md) | Six ways to call a published data agent (Python, Node, VS Code, a Fabric app function, your own backend, the portal), and whose identity each one uses |
| [`response-formatting/`](response-formatting/README.md) | An agent-instructions template with an answer format, real sample answers, and a parser that turns an answer into tables and charts |
